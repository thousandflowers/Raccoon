Screenshots for the Raycast store go here.

Take them with Raycast's own **Window Capture** command while the extension is
running in development mode: it writes a correctly sized PNG straight into this
folder. Hand-cropped images from a normal screenshot are the wrong size and the
review sends them back.

Up to six. The order in this folder is the order the store shows them, so the
first should be the one that explains what the extension is: the security audit
list, with its colours and the fix on Enter.
